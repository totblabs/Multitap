자세히

콘솔 도움말

화면을 누르면 키보드 입력이 데스크톱으로 가요.
Ctrl+Alt+Del은 위쪽 도구에서 보내세요.

브라우저가 예약한 단축키는 PC에서 실행될 수 있어요.
전체 키 전달과 일반 업무는 설치형 클라이언트를 사용하세요.

Console은 비상용이에요.
일반 업무는 스트리밍으로 연결하세요.

화면·한글·클립보드 호환성

연결됨 표시는 Windows 로그인이나 화면 준비 완료를 뜻하지 않아요. QEMU 콘솔이 꺼져 있으면 화면이 보이지 않을 수 있어요.

한글은 Host가 읽어 준 한/영 상태에 맞춰 보내요. Host가 상태를 알려 주지 못하면 영어·숫자·기호만 보내요. 기존 VNC 클립보드는 Latin-1 문자만 전송해요.

연결을 닫아도 데스크톱 전원과 실행 중인 작업은 유지돼요. 자동 재연결은 하지 않아요.

오픈소스 안내

noVNC 1.7.0을 원본 그대로 포함해요. MPL-2.0과 포함 라이선스는 오픈소스 안내에서 확인하세요.

텍스트 클립보드

관리자가 허용한 방향으로만 사용할 수 있어요.
한글 등 Latin-1 밖의 문자는 전송하지 않아요.

기존 로그인 연결을 종료할까요?

로그인하면 기존 원격·콘솔 연결이 종료돼요.
데스크톱과 실행 중인 작업은 유지돼요.

복구 코드는 사용됐어요. 취소해도 다시 쓸 수 없어요.

콘솔을 닫을까요?

데스크톱과 작업은 그대로 유지돼요.
