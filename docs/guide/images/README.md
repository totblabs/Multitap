# 가이드북 화면 예시

Multitap 앱·관리자 페이지를 예제 데이터로 렌더링한 화면입니다.
계정·서버 주소·데스크톱·상태·속도·버전 표시는 모두 예시입니다.
화면에 표시된 버전은 현재 배포 버전이나 설치 완료를 뜻하지 않습니다.

| 파일 | 내용 |
| --- | --- |
| `client-signin.jpg` | Windows 로그인 화면 |
| `client-launcher.jpg` | Windows 데스크톱 목록과 상태별 카드 |
| `client-toolbar.png` | Windows 세션 툴바와 화면 패널(배율) |
| `client-settings.jpg` | Windows 스트리밍 설정 |
| `host-server.png` | Host의 서버 연결 (등록 전) |
| `host-windows-login.png` | Host의 Windows 로그인 (계정 저장 전) |
| `host-display.png` | Host의 가상 화면 상태 |
| `host-devices.png` | Host의 장치 준비 상태 |
| `admin-desktops.png` | 관리자 페이지의 데스크톱: 승인 대기, 문제 먼저, 고른 데스크톱의 해결·전원·쓰는 사람 |
| `admin-users.png` | 관리자 페이지의 사용자: 데스크톱 배정과 공유 선택 |
| `admin-monitoring.png` | 관리자 페이지의 모니터링: 사람별 연결 시간 |
| `admin-proxmox.png` | 관리자 페이지의 Proxmox 연결 (연결된 상태) |
| `admin-proxmox-setup.png` | 관리자 페이지의 Proxmox 연결 (처음 설정, 복사할 명령어) |
| `android-launcher.png` | Android 데스크톱 목록 |
| `android-session.png` | Android 앰버색 버튼 세 개와 열린 세션 메뉴 |

실제 코드를 예제 데이터로 그린 화면입니다. 기기에서 찍은 스크린샷이 아니어서 실제 영상 화면, 시스템 표시줄, 키보드는 들어 있지 않습니다.
사진 배경이 있는 Windows 화면은 JPEG, 나머지는 PNG입니다. 일부는 화면의 필요한 부분만 잘랐습니다.
화면마다 창 크기가 다르며, Android는 스마트폰의 세로 배치를 유지합니다.

사용자 환경의 권한·장치·창 크기에 따라 보이는 메뉴와 상태는 달라질 수 있습니다.
배경 이미지 등 앱 구성 자료의 출처는 [외부 구성요소 고지](../../../THIRD_PARTY_NOTICES.md)를 따릅니다.
