# Multitap for Proxmox VE 가이드북

[English](en/README.md)

이 가이드북은 화면과 설정을 모두 다루는 자세한 참고서입니다. 처음 설치한다면 [홈페이지의 가이드](https://multitap.me/ko/guide/)가 더 짧습니다. 설치부터 첫 연결까지 아홉 장으로 안내하고, 자세한 내용이 필요할 때 이 가이드북으로 돌아오면 됩니다.
아래에서 **계정을 받은 사용자**인지, **처음 설치하는 관리자**인지 고르세요.

## 계정을 받았어요 — 데스크톱에 연결하기

관리자에게 **서버 주소·아이디·초기 비밀번호**를 받으세요.
사용할 기기의 안내를 따라가면 됩니다.

- **Windows PC:** [6장: 앱 설치부터 첫 연결까지](06-Windows-클라이언트.md#처음-연결하는-순서)를 따라가세요.
- **Android 휴대폰·태블릿:** [7장: 앱 설치부터 첫 연결까지](07-Android.md#처음-연결하는-순서)를 따라가세요.

사용자에게 필요한 순서는 **앱 설치 → 서버 주소 확인 → 로그인 → 스트리밍 연결**입니다.

## 내가 처음 설치해요 — 데스크톱 한 대부터 연결하기

처음에는 **Windows VM 한 대와 사용자 한 명**으로 연결을 확인하세요.
그다음 같은 순서로 다른 데스크톱을 추가하면 됩니다.

먼저 [소개와 준비물](01-소개.md)에서 설치할 컴퓨터를 구분하세요.
그다음 아래 여섯 단계로 진행합니다.

1. **서버 설치:** 명령 한 줄로 [Linux 서버에 Multitap을 설치](02-서버-설치.md#서버-설치)하고 실행하세요.
2. **서버 기본 설정:** [관리자 계정과 접속 주소를 설정](02-서버-설치.md#서버-기본-설정)하세요.
3. **Proxmox 연동:** 관리자 페이지와 Proxmox Shell에서 [Proxmox를 연결](03-Proxmox-연결.md)하세요. **연결됨**이 보이면 다음으로 갑니다.
4. **Host 설치·승인:** [데스크톱이 될 Windows 안에 Host를 설치](04-Host-설치.md)하세요. 설치 마무리·관리자 승인·Windows 계정을 확인합니다.
5. **사용자·데스크톱 배정·공유:** [사용자 계정을 만들고 데스크톱을 배정](05-사용자와-VM-배정.md)하세요.
6. **클라이언트 연결:** PC·휴대폰에 [Windows 앱](06-Windows-클라이언트.md#처음-연결하는-순서) 또는 [Android 앱](07-Android.md#처음-연결하는-순서)을 설치해 연결하세요.

**Host는 데스크톱이 될 Windows 안에, 클라이언트는 지금 조작할 기기에 설치합니다.**
서버 설치만 끝난 상태에서는 아직 데스크톱 화면이 나오지 않습니다.
