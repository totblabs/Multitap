# 1. 소개

[목차](README.md) · [다음: 서버 설치](02-서버-설치.md) · [English](en/01-introduction.md)

Multitap for Proxmox VE는 셀프 호스팅 Proxmox VDI입니다.
직접 운영하는 서버로 Proxmox VE의 Windows VM을 PC나 휴대폰에서 씁니다.
관리자가 데스크톱을 배정하면, 사용자는 앱에서 그 데스크톱에 연결합니다.

**데스크톱**은 원격으로 쓰는 Windows입니다. Proxmox의 Windows VM이거나, Host를 설치한 실제 Windows PC(**로컬 PC**)입니다.
**VM**은 Proxmox 안에서 실행하는 가상 컴퓨터입니다.

## 먼저 세 위치를 구분하세요

| 이 가이드의 표현 | 뜻 | 예시 |
| --- | --- | --- |
| PC | 지금 앞에서 마우스·키보드로 조작하는 컴퓨터 | 집의 노트북 |
| 데스크톱 | 원격으로 쓰는 Windows | Proxmox 안의 Windows VM, 사무실 Windows PC |
| Linux 서버 | 로그인과 연결을 중계하는 컴퓨터 | Multitap 서버를 설치한 Linux CT나 VM |

Host 설치 파일은 **데스크톱이 될 Windows 안에서** 실행하세요.
클라이언트 설치 파일은 **PC에서** 실행하세요.

## 어떤 프로그램을 어디에 설치하나요?

| 구성 요소 | 설치 위치 | 하는 일 |
| --- | --- | --- |
| 서버(브로커) | Linux 서버 | 로그인, 사용자 배정, 화면 중계, 관리자 페이지를 제공합니다. |
| Host | 데스크톱이 될 Windows VM 또는 PC | 화면과 소리를 보내고 키보드·마우스 입력을 받습니다. |
| Windows 클라이언트 | 사용자의 Windows PC | 배정받은 데스크톱에 연결합니다. |
| Android 클라이언트 | 사용자의 휴대폰·태블릿 | 배정받은 데스크톱에 연결합니다. |

```text
Windows / Android 클라이언트
             ↕
      Multitap 서버(브로커) ── Proxmox VE
             ↕               VM 목록·전원·Console
       Windows Host
        VM 또는 PC
```

Host와 클라이언트는 같은 Multitap 서버에 연결합니다.
서로 같은 내부망에 있지 않아도 서버의 중계를 이용합니다.

> 화면은 서버를 거쳐 전달됩니다.
> 종단 간 암호화 방식은 아닙니다. [보안 안내](10-보안-안내.md)를 확인하세요.

## 준비물

| 대상 | 준비할 것 |
| --- | --- |
| 서버 | Debian 또는 Ubuntu x86_64 CT나 VM, 인터넷 연결. Docker는 설치 명령이 함께 설치합니다 |
| Proxmox | VM을 관리할 수 있는 Proxmox VE와 노드의 root Shell 접근 권한 |
| Host | Windows 10/11 x64 VM 또는 PC, 설치할 때 사용할 관리자 권한 |
| Windows 클라이언트 | Windows 10/11 x64 PC |
| Android 클라이언트 | Android 8.0 이상 기기 |
| 인터넷에서 접속 | 서버 도메인, HTTPS 인증서, 방화벽·공유기 설정 권한 |

서버를 처음 설치하는 관리자는 **Linux에 로그인할 수 있는 상태**부터 준비하세요.
Proxmox와 Linux 운영체제의 설치 자체는 이 가이드의 범위에 포함되지 않습니다.

### 지원하지 않는 것

- Mac·iOS·Linux용 클라이언트는 없습니다. 클라이언트는 Windows와 Android뿐입니다.
- Android에서는 USB 장치를 쓸 수 없습니다.
- 마이크와 카메라 전달은 지원하지 않습니다.
- 데스크톱은 Windows만 됩니다. Host는 Windows 10/11 x64용입니다.

Docker는 Linux 서버에서 프로그램을 묶어 실행하는 도구입니다.
Compose는 `compose.yaml`이라는 파일을 읽어 Multitap 서버를 실행합니다.

GPU가 없는 Windows VM도 사용할 수 있습니다.
화질과 프레임은 VM 성능, 인코더, 네트워크 상태에 따라 달라집니다.

내부망에서는 인증서 없이 HTTP로 운영할 수도 있습니다.
HTTP는 로그인 정보와 화면을 암호화하지 않습니다.

## 비밀번호는 어디의 비밀번호인가요?

| 화면·작업 | 사용할 계정 |
| --- | --- |
| Multitap 앱 로그인 | 관리자가 만든 Multitap 사용자 계정 |
| Multitap 관리자 페이지 로그인 | 서버를 처음 설정하며 바꾼 관리자 계정 |
| Host의 **Windows 로그인** | 그 VM·PC에 실제 로그인할 Windows 계정. PIN 대신 비밀번호 사용 |
| Proxmox 웹과 **Shell** | Proxmox 관리자 계정 |
| 서버 터미널·SSH | Linux 서버를 설치할 때 만든 Linux 계정 |

이 계정들은 서로 다릅니다.
Multitap 아이디를 만들었다고 Windows 계정도 만들어지는 것은 아닙니다.
