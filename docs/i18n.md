# Korean and English (i18n)

Every screen ships in Korean and English.
Korean is the source text. English is a translation of it, never a rewrite of
meaning. This file is the shared rule set for every part of the product.

## Which language

| Part | Picks the language from | Override |
|---|---|---|
| Admin console (server/admin) | browser `navigator.languages` | top-bar language switch, stored per browser (localStorage, wrapped in try/catch) |
| Windows / Android client, Host settings (Flutter) | system locale | app setting "언어 / Language" (자동, 한국어, English), stored with the other app settings |
| Host service, tray, installers (C++) | `GetUserDefaultUILanguage()` | none (follows Windows) |
| install.sh, multitap (bash) | `MULTITAP_LANG`, else `LC_ALL` / `LC_MESSAGES` / `LANG` | `MULTITAP_LANG=ko|en` |
| proxmox.py | `--lang ko|en`, else `MULTITAP_LANG`, else locale | the admin console adds `--lang` matching its own language to the command it shows |
| Server responses | error codes; any human text the server must send is chosen from the request's `Accept-Language` (ko first → Korean, else English) | — |

Rule: Korean when the chosen locale starts with `ko`, English otherwise.
Unknown or missing locale → English, except where the product already has a
Korean-speaking context (e.g. a command copied from a Korean admin page carries `--lang ko`).

## Style

- English: short, plain, sentence case, friendly but not chatty. Second person ("you"), present tense. No exclamation marks.
- Same length budget as the Korean (2–3 lines of guidance; details behind help).
- Keep product names, codes, commands, paths, numbers and placeholders exactly; translate only words.
- Do not translate log/diagnostic codes, API field names, test hooks or keys.
- Numbers, dates and times use the locale (Korean "11월 11일", English "Nov 11").
- One string per message; never build sentences by joining translated pieces whose order differs between languages — use placeholders (`{count}대` / `{count} desktops`).

## Tests

- Existing tests keep running in Korean (they pin the Korean text, which stays the source).
- Each part adds tests that switch to English and check: no Hangul left on the main screens, the language switch works, and placeholders are filled.
